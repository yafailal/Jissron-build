Two payment rails. International learners pay USD via Lemon Squeezy (checkout → webhook → Order PAID → Enrollment). Moroccan learners pay MAD via bank transfer (Order PENDING → admin marks PAID → Enrollment). Free courses enroll directly. Prices are stored per-currency on each Course (priceMadCents / priceUsdCents).

Core User Flows

Enroll (paid · international)
Browse course→ Checkout→ Lemon Squeezy→ webhook → Order PAID→ Enrollment ACTIVE→ Learn (Bunny video)
Enroll (paid · Morocco / MAD)
Checkout — bank transfer→ Order PENDING + receipt→ Admin reviews → mark PAID→ Enrollment ACTIVE
Learn & assess
Watch lesson→ LessonProgress.watchedSecs→ Quiz / Assignment→ progressPct → completedAt→ Review
RBAC enforced at the edge. middleware.ts gates /dashboard (any authenticated user) and /admin (ADMIN role only), redirecting non-admins to their dashboard. All public-site content (hero, CTAs, footer, nav, pages, FAQ) is database-driven via SiteSettings + Page + FAQ — editable from the admin panel, never hardcoded.
